# NovaCMD

Terminal Windows moderne et portable : vrai moteur ConPTY, onglets, Git Bash, comptes locaux protégés et paramètres complets.

## Télécharger

Dernière version : **[v1.0.0](https://github.com/powercore649/NovaCMD/releases/latest)**

- `NovaCMD-x64.exe` — PC Intel/AMD 64 bits
- `NovaCMD-arm64.exe` — Windows on ARM

Aucune installation : lance directement l'exécutable.

## Fonctionnalités

- ConPTY natif (couleurs, applications interactives)
- Onglets et choix du shell : NovaCMD (cmd propre) ou Git Bash
- Comptes locaux avec mots de passe hachés (scrypt) et écran de verrouillage
- Paramètres : thème, police, curseur, historique, recherche, copier/coller, zoom
- Exe portable, données et réglages locaux (`%APPDATA%\NovaCMD`)

## Configuration

Windows 10 1809 ou plus récent. L'exécutable n'est pas signé : SmartScreen peut demander une confirmation.
